# 简历可复用描述

## 项目名称

AI 驱动自动化测试全流程插件原型及 React + Flask 登录注册 Demo

## 项目描述

设计并实现一个用于验证 AI 自动化测试闭环的最小原型项目，基于 React + Flask + SQLite 构建登录注册 Demo 系统，并围绕 PRD 解析、需求拆解、测试用例设计、自动化接口执行、测试报告生成、Bug 单沉淀完成端到端验证。

## 个人职责

- 使用 React、Axios、React Router、Ant Design 开发登录注册前端页面。
- 使用 Flask + SQLite 开发注册、登录和健康检查接口。
- 编写 PRD、需求分析、测试用例、测试报告和标准化 Bug 单。
- 人工预埋用户名长度校验缺陷，模拟真实测试发现过程。
- 设计 AI 自动化测试插件最小架构，覆盖 PRD 解析、用例生成、执行、报告和 Bug 推送链路。

## 项目亮点

- 完成从开发到测试再到缺陷管理的完整闭环。
- 通过预埋业务规则缺陷验证自动化测试用例生成价值。
- 具备后续扩展为插件化工具的架构基础。
- 体现开发、测试、质量分析和 AI 工程化结合能力。
