# Bug 单

## Bug 标题

注册接口未校验用户名最小长度，短用户名可注册成功

## 基本信息

| 字段 | 内容 |
| --- | --- |
| Bug 编号 | BUG-REG-001 |
| 严重级别 | P1 |
| 优先级 | 高 |
| 所属模块 | 用户注册 |
| 关联需求 | REG-002 |
| 发现方式 | 自动化接口测试 + 手工测试 |
| 当前状态 | 待修复 |

## 前置条件

系统服务已启动，测试数据库中不存在用户名 `abc`。

## 复现步骤

1. 调用注册接口 `POST /api/register`。
2. 请求体传入 `{"username":"abc","password":"secret123"}`。
3. 查看接口响应。

## 预期结果

接口返回 400，提示“用户名长度不能少于6位”。

## 实际结果

接口返回 201，提示“注册成功”，并写入短用户名。

## 影响范围

- 不符合 PRD 验收标准。
- 脏数据进入用户表。
- 前后续系统如依赖用户名长度规则，可能产生兼容问题。

## 建议修复

在后端 `/api/register` 中增加 `len(username) < 6` 校验，前端注册表单同步增加 `min: 6` 校验。
