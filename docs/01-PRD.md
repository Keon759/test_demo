# 登录注册 Demo 系统 PRD

## 1. 项目目标

构建一个前后端分离的简易登录注册系统，用于验证 AI 自动化测试插件从 PRD 解析、需求拆解、测试用例生成、执行、报告生成到自动提 Bug 的完整流程。

## 2. 用户角色

- 未注册用户：可注册新账号。
- 已注册用户：可使用账号密码登录系统。
- 测试人员/插件原型：可基于需求生成并执行测试用例。

## 3. 功能需求

### 3.1 用户注册

- 用户输入用户名和密码后提交注册。
- 用户名不能为空。
- 用户名长度必须大于等于 6 位。
- 用户名不可重复。
- 密码不能为空。
- 密码长度必须大于等于 6 位。
- 注册成功后返回成功提示。

### 3.2 用户登录

- 用户输入用户名和密码后提交登录。
- 用户名不能为空。
- 密码不能为空。
- 用户名或密码错误时返回错误提示。
- 登录成功后进入登录成功页面。

## 4. 非功能需求

- 后端接口响应格式使用 JSON。
- 前端页面简洁清晰，能完成核心流程。
- 数据使用 SQLite 存储。
- 系统可本地启动，便于测试验证。

## 5. 验收标准

- 可完成合法用户注册。
- 可拦截空用户名、空密码、短密码、重复用户名。
- 应拦截长度小于 6 位的用户名。
- 合法用户可登录。
- 错误密码不可登录。

## 6. 已知预埋缺陷

当前初版代码刻意未实现“用户名长度必须大于等于 6 位”的校验，用于验证测试流程是否能发现并自动生成 Bug 单。
